# 디자인 시스템

앱 대부분은 macOS 기본 색·글꼴(SwiftUI `.primary`/`.secondary`, 시스템 글꼴)을 쓴다. 아래는 CPU 캐릭터 화면이 따로 쓰는 값이고, 코드는 `Sources/Backstage/ProcsView.swift`의 `Palette`에 있다.

## 색

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `window` | `#f6f6f8` | `#1e1e21` | 무대·상세 칸 바탕 |
| `surface` | `#ffffff` | `#2a2a2e` | 확인창, '그 밖에 N개' 칩 |
| `line` | `#d9d8de` | `#3a3a3f` | 테두리, 상세 칸 줄 |
| `floor` | `#e4e2ea` | `#26252b` | 바닥 띠, 게이지 바탕 |
| `ok` / `warm` / `hot` | `#34c759` / `#ff9f0a` / `#ff453a` | 같음 | 캐릭터 몸 색(CPU 0 → 40 → 80% 이상), 게이지, 종료 버튼(`hot`) |

몸 위 얼굴(`#1d1d1f`), 볼(`#ff6b8a` 55%), 땀(`#7cc8ff`)은 몸 색 위에만 올라가서 테마와 상관없이 같다.

## 글자
- 캐릭터 이름 11pt semibold, 퍼센트 11pt 보조색. 상세 칸 앱 이름 16pt semibold, CPU 30pt bold(몸 색), 표 줄 13pt, 안내 11pt 3단계색. 요약 줄 12pt.

## 크기·간격
- 캐릭터: `s = √(min(CPU,200)/200)`, 몸 폭 `44 + 118s`, 높이 `48 + 96s`, 모자(아이콘) `16 + 10s`. 캐릭터 사이 6pt, 바닥 띠 46pt, 상세 칸 폭 260pt.
- 폭이 모자라면 무대 전체를 줄인다(늘리지는 않음). 캐릭터는 CPU 상위 7개, 나머지는 '그 밖에 N개 · 표에서 보기'.
- 모서리: 무대 틀 10, 확인창 12, 버튼 7.

## 기분
| CPU | 기분 | 얼굴 | 효과 |
|---|---|---|---|
| < 1% | sleep | 감은 눈 | zz |
| < 15% | happy | 동그란 눈, 웃는 입 | |
| < 50% | busy | 동그란 눈, 일자 입 | |
| < 100% | sweat | `> <` 눈, 볼 | 땀방울, 떨기 |
| ≥ 100% | boil | 같음 | 땀방울, 떨기, 김 |

숨쉬기 주기는 `max(0.35, 3.2 − CPU/35)`초. 동작 줄이기를 켜면 모두 멈춘다.

## 컴포넌트
- `DangerButtonStyle`: 빨간 바탕 흰 글자. 종료·강제 종료에만 쓴다.
- 확인창(`QuitSheet`): 무대 위 반투명 덮개 + 가운데 위쪽 카드(폭 320). 단계: 확인 → 기다리는 중(초 세기) → 안 꺼짐(기다리기 / 강제 종료).
