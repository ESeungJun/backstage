# 결정기록

## 2026-11-12 · 실행 중인 프로그램 탭을 CPU 캐릭터로

- **정한 것**: 맨 처음 시안(말랑 블롭 + 앱 아이콘 모자, 바닥 띠)을 그대로 쓴다. 2D SwiftUI 그림 + Core Animation 움직임.
- **거친 시안**: 1차 블롭/무대 → 2차 모양 비교 → 3차 파스텔 찐빵 → 4차 Canvas 소프트바디 젤리 → 5차 three.js 3D 젤리.
  사용자가 1차 블롭을 골랐다(검토 자료: `~/Documents/검토요청/2026-11-12_Backstage-CPU시안/`).
- **3D(RealityKit)를 안 쓴 이유**: SwiftUI 안에 3D를 넣으려면 최소 macOS를 15로 올려야 하고, GPU를 계속 써서 CPU 모니터와 맞지 않는다.
- **정리 범위**: 정상 종료 + 확인. 앱은 정상 종료 요청, 그 밖은 SIGTERM. 5초 뒤에도 살아 있으면 강제 종료 버튼. 시스템 프로그램과 Backstage 자신은 버튼 없음.
- **묶기**: 앱 단위. 가장 바깥 `.app` 번들로 도우미를 합친다. 앱이 아닌 실행 파일은 경로가 같으면 합친다(`node` 여러 개 → 하나).
- **요약 줄 이름**: 시안의 '전체 CPU' 대신 '내 프로그램 CPU'. 시스템 프로세스를 빼고 더한 값이라 '전체'라고 하면 틀린다.
- **README '읽기 전용'**: '작업은 읽기만'으로 고치고, 끌 수 있는 건 사용자가 고르고 확인한 프로그램뿐이라고 적었다.
