# 결정기록

## 2026-11-12 · 실행 중인 프로그램 탭을 CPU 캐릭터로

- **정한 것**: 맨 처음 시안(말랑 블롭 + 앱 아이콘 모자, 바닥 띠)을 그대로 쓴다. 2D SwiftUI 그림 + Core Animation 움직임.
- **거친 시안**: 1차 블롭/무대 → 2차 모양 비교 → 3차 파스텔 찐빵 → 4차 Canvas 소프트바디 젤리 → 5차 three.js 3D 젤리.
  사용자가 1차 블롭을 골랐다(검토 자료: `~/Documents/검토요청/2026-11-12_Backstage-CPU시안/`).
- **3D(RealityKit)를 안 쓴 이유**: SwiftUI 안에 3D를 넣으려면 최소 macOS를 15로 올려야 하고, GPU를 계속 써서 CPU 모니터와 맞지 않는다.
- **정리 범위**: 정상 종료 + 확인. 앱은 정상 종료 요청, 그 밖은 SIGTERM. 5초 뒤에도 살아 있으면 강제 종료 버튼. 시스템 프로그램과 Backstage 자신은 버튼 없음.
- **묶기**: 앱 단위. 가장 바깥 `.app` 번들로 도우미를 합친다. 앱이 아닌 실행 파일은 합치지 않는다(`node` 여러 개가 서로 다른 일을 할 수 있어서, 하나를 끄려다 전부 끄지 않게).
- **요약 줄 이름**: 시안의 '전체 CPU' 대신 '내 프로그램 CPU'. 시스템 프로세스를 빼고 더한 값이라 '전체'라고 하면 틀린다.
- **README '읽기 전용'**: '작업은 읽기만'으로 고치고, 끌 수 있는 건 사용자가 고르고 확인한 프로그램뿐이라고 적었다.

## 2026-11-13 무대 크기, 메뉴바 카드, 앱 아이콘
- **무대 빈 곳**: 캐릭터를 무대 높이에 맞춰 최대 2배까지 직접 크게 그린다. 폭이 모자라면 무대에 올리는 수를 7개에서 4개까지 줄인다. '그 밖에' 메뉴는 무대 오른쪽 위로 옮겼다.
- **메뉴바 패널**: CPU 제일 많이 쓰는 앱 하나만 캐릭터로 보여 준다. 패널이 열려 있는 동안만 ps 를 돈다.
- **앱 아이콘**: 커튼 + 시계 대신 밝은 바탕의 큰 초록 캐릭터 하나(B안). 세 시안(무대 + 캐릭터 / 큰 캐릭터 / 세 캐릭터) 중 사용자가 골랐다. 작은 크기에서 가장 또렷하다. 검토 자료: `~/Documents/검토요청/2026-11-13_Backstage-아이콘시안/`.
- **메뉴바 아이콘**: `curtains.closed` 가 메뉴바 크기에서 수건걸이처럼 보인다는 사용자 의견으로, 앱 아이콘과 같은 캐릭터 실루엣(18pt 템플릿, 눈·입은 뚫음)으로 바꿨다. 실패 경고일 때는 SF Symbol 경고 삼각형 + 개수.
- **자기 CPU**: Backstage 는 ps 를 부르는 순간 목록을 모으느라 바빠서 ps 순간값이 부풀려진다(창 열 때 37%, 갱신 때 10~18%, 나머지 0%). 목록의 자기 줄은 갱신 사이 평균(getrusage)으로 바꿔 넣는다.
- **문구**: 화면 문구를 해요체로 통일. `이(가)`·`을(를)` 대신 이름에 맞춰 조사를 고르고, 영어 이름이면 "앱"·"프로그램"을 붙인다.
